# Word lists

Lists gather signs: the ones you are learning, the ones of a course, of a job… You need an
[account](/help/account).

## Creating a list

- In **My lists**, give the new list a name.
- From the page of a sign, create a list that already holds the sign.
- From search results, choose "New list…" and give it a name.

## Adding signs

- On the **page of a sign**, click "Add" next to a list; "Remove" takes the sign out.
- In **search results**, select signs then "Add the selection", or add all the results of the search (a thousand at
  most) with "Add all the results".

Signs stay in the order you added them.

## Managing a list

On the page of a list you can remove signs, rename the list, delete it and [export](/help/exports) it. When a sign is
no longer in the lexicon (the data changed), the list says so.

Only you see your lists.
