# Wortlisten

Listen fassen Gebärden zusammen: jene, die Sie lernen, die eines Kurses, eines Berufs… Sie brauchen dafür ein
[Konto](/help/account).

## Eine Liste erstellen

- Geben Sie unter **Meine Listen** der neuen Liste einen Namen.
- Erstellen Sie auf der Seite einer Gebärde eine Liste, die diese Gebärde schon enthält.
- Wählen Sie in den Suchergebnissen «Neue Liste…» und geben Sie ihr einen Namen.

## Gebärden hinzufügen

- Klicken Sie auf der **Seite einer Gebärde** neben einer Liste auf «Hinzufügen»; «Entfernen» nimmt sie heraus.
- Wählen Sie in den **Suchergebnissen** Gebärden aus und dann «Auswahl hinzufügen», oder fügen Sie mit «Alle
  Ergebnisse hinzufügen» alle Ergebnisse der Suche hinzu (höchstens tausend).

Die Gebärden bleiben in der Reihenfolge, in der Sie sie hinzugefügt haben.

## Eine Liste verwalten

Auf der Seite einer Liste können Sie Gebärden entfernen, die Liste umbenennen, löschen und
[exportieren](/help/exports). Ist eine Gebärde nicht mehr im Lexikon (die Daten haben sich geändert), zeigt die Liste
es an.

Nur Sie sehen Ihre Listen.
