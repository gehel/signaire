# Eine Gebärde anfragen

Fehlt eine Gebärde? Fragen Sie die Verwaltung: Sie sucht sie auf SignSuisse und fügt sie hinzu, wenn sie sie findet.

- Geben Sie unter **Meine Anfragen** das Wort oder den Ausdruck, die Gebärdensprache und, wenn Sie wollen, einen
  Kommentar (Bedeutung, Kontext) an.
- Findet eine Suche nichts, füllt der Link «anfragen» das Wort für Sie aus.

Sie brauchen ein [Konto](/help/account).

## Anfragen verfolgen

**Meine Anfragen** zeigt Ihre Anfragen und ihren Stand:

- **Offen**: Die Verwaltung hat sie noch nicht bearbeitet;
- **Hinzugefügt**: Die Gebärde ist im Lexikon, ein Link führt dorthin;
- **Abgelehnt**: Die Gebärde konnte nicht hinzugefügt werden.
