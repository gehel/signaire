# Votre compte

Chercher et consulter les signes ne demande pas de compte. Il en faut un pour les [listes](/help/lists) et les
[demandes](/help/requests).

## Créer un compte

Choisissez « Se connecter » puis « Créer un compte » :

- le **nom d'utilisateur** compte 3 à 40 caractères : lettres sans accents, chiffres, points, tirets ou soulignés ;
  les majuscules ne comptent pas ;
- le **nom affiché** est facultatif : c'est le nom que Signaire affiche ;
- le **mot de passe** compte au moins 8 caractères.

Selon la configuration, la création de comptes peut être fermée, ou la connexion possible avec un autre compte
(OpenID Connect) : un bouton « Se connecter avec… » apparaît alors. Votre compte Signaire est créé à la première
connexion.

## Se déconnecter

« Se déconnecter » est dans l'en-tête de chaque page.
