# Listes de mots

Les listes regroupent des signes : ceux que vous apprenez, ceux d'un cours, d'un métier… Il faut un
[compte](/help/account) pour en avoir.

## Créer une liste

- Dans **Mes listes**, donnez un nom à la nouvelle liste.
- Depuis la page d'un signe, créez une liste qui contient déjà ce signe.
- Depuis les résultats d'une recherche, choisissez « Nouvelle liste… » et donnez-lui un nom.

## Ajouter des signes

- Sur la **page d'un signe**, cliquez sur « Ajouter » à côté d'une liste ; « Retirer » l'enlève.
- Dans les **résultats d'une recherche**, cochez des signes puis « Ajouter la sélection », ou ajoutez tous les
  résultats de la recherche (mille au plus) avec « Ajouter tous les résultats ».

Les signes restent dans l'ordre où vous les avez ajoutés.

## Gérer une liste

Sur la page d'une liste, vous pouvez retirer des signes, renommer la liste, la supprimer et l'[exporter](/help/exports).
Si un signe n'est plus dans le lexique (les données ont changé), la liste l'indique.

Vos listes ne sont visibles que par vous.
