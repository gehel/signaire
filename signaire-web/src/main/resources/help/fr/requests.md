# Demander un signe

Un signe manque ? Demandez-le aux administrateurs : ils le cherchent sur SignSuisse et l'ajoutent s'ils le trouvent.

- Dans **Mes demandes**, indiquez le mot ou l'expression, la langue des signes et, si vous voulez, un commentaire
  (le sens, le contexte).
- Quand une recherche ne trouve rien, le lien « Demander » remplit le mot pour vous.

Il faut un [compte](/help/account).

## Suivre ses demandes

**Mes demandes** liste vos demandes et leur état :

- **En attente** : les administrateurs ne l'ont pas encore traitée ;
- **Ajouté** : le signe est dans le lexique, un lien y mène ;
- **Refusé** : le signe n'a pas pu être ajouté.
