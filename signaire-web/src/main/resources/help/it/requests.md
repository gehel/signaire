# Richiedere un segno

Manca un segno? Chiedilo all'amministrazione: lo cerca su SignSuisse e lo aggiunge se lo trova.

- In **Le mie richieste**, indica la parola o l'espressione, la lingua dei segni e, se vuoi, un commento
  (significato, contesto).
- Quando una ricerca non trova nulla, il link «Richiedi» compila la parola per te.

Serve un [account](/help/account).

## Seguire le richieste

**Le mie richieste** elenca le tue richieste e il loro stato:

- **In attesa**: l'amministrazione non l'ha ancora trattata;
- **Aggiunto**: il segno è nel lessico, un link porta al segno;
- **Rifiutato**: il segno non ha potuto essere aggiunto.
