# Liste di parole

Le liste raggruppano segni: quelli che stai imparando, quelli di un corso, di un mestiere… Serve un
[account](/help/account).

## Creare una lista

- In **Le mie liste**, dai un nome alla nuova lista.
- Dalla pagina di un segno, crea una lista che contiene già quel segno.
- Dai risultati di una ricerca, scegli «Nuova lista…» e dalle un nome.

## Aggiungere segni

- Sulla **pagina di un segno**, clicca «Aggiungi» accanto a una lista; «Togli» lo rimuove.
- Nei **risultati di una ricerca**, seleziona dei segni e poi «Aggiungi la selezione», oppure aggiungi tutti i
  risultati (al massimo mille) con «Aggiungi tutti i risultati».

I segni restano nell'ordine in cui li hai aggiunti.

## Gestire una lista

Sulla pagina di una lista puoi togliere segni, rinominare la lista, eliminarla ed [esportarla](/help/exports). Se un
segno non è più nel lessico (i dati sono cambiati), la lista lo indica.

Solo tu vedi le tue liste.
