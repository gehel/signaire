# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/gehel/signaire/security/advisories/new) ("Report a
vulnerability" in the Security tab), rather than in a public issue.

Say what is affected (web application, standalone application, command line, Android app), how to reproduce it, and
what an attacker gains. A proof of concept helps; please don't test against servers or accounts that aren't yours,
nor against SignSuisse.

## What to expect

- An acknowledgement within 7 days.
- A fix, or an agreed date for one, within 90 days of the report. The vulnerability is disclosed with the fix, through
  a GitHub security advisory that credits the reporter unless they prefer otherwise.

## Supported versions

Signaire has no release yet: fixes go to the `main` branch. Once releases are published, the latest one is supported.

## Out of scope

SignSuisse, its site and its content belong to the SGB-FSS: report problems with them to the SGB-FSS.
